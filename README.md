# 北海道九日旅行手帳

## 檔案
- `index.html` 網頁主架構
- `style.css` 外觀與滑動覆蓋設計
- `itinerary.js` 九天行程與準備清單（要改行程請修改這裡）
- `script.js` 切換日期、Google 搜尋、勾選清單與夜間模式

## GitHub Pages 部署
1. 在 GitHub 建立公開 repository，例如 `hokkaido-trip`。
2. 將四個檔案上傳到 repository 根目錄（不要只上傳 zip）。
3. Settings → Pages → Build and deployment → Deploy from a branch。
4. 選 `main` 與 `/(root)`，按 Save。
5. 網址通常為 `https://你的帳號.github.io/hokkaido-trip/`。

## 注意
這是從上傳的 `.pages` 檔案可辨識的文字整理成初版。部分原始時段、日期及住宿資訊無法完整可靠地還原，因此使用「待確認」及概略時段。請依原始文件核對後修改 `itinerary.js`。
背景目前為線上 Unsplash 風景照片，非特定北海道照片；可改成你自己的北海道照片並更新 `style.css` 的 `.hero` 背景 URL。
